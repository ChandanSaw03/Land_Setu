LANDSETU DEMO WEBSITE
=====================

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Safari, or Firefox.
3. No installation, server, or internet connection is required.

Included pages:
- Dashboard
- Projects (search, filters, pagination, add/view/delete project)
- AI Insights
- Map
- Reports (CSV export)
- Settings (interactive preferences)

Notes:
This is a front-end demo. The dashboard figures and risk visuals are sample/demo data,
not live government records or a connected AI model. Projects added or deleted during
the session update the in-page demo data; there is no server/database connection.
